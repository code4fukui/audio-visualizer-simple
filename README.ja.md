# Audio Visualizer Simple

Web Audio API を活用したシンプルなオーディオビジュアライザです。

## デモ
[ライブデモを実行](https://code4fukui.github.io/audio-visualizer-simple/)

## 機能
- Web Audio API を使用した音声入力のビジュアライズ
- 音声入力デバイスの選択に対応
- さまざまなビジュアライズモードのオプションを提供

## 要件
本プロジェクトには、Web Audio API をサポートするモダンブラウザが必要です。

## 使い方
1. 対応ブラウザで[ライブデモ](https://code4fukui.github.io/audio-visualizer-simple/)を開きます。
2. ドロップダウンから使用する音声入力デバイスを選択します。
3. スライダーを使用して入力ゲインを調整します。
4. ドロップダウンからビジュアライズモードを選択します。
5. キャンバス上に音声入力がビジュアライズされます。
