# Audio Visualizer Simple

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A Web Audio API-powered simple audio visualizer.

## Demo
[Run the demo live](https://code4fukui.github.io/audio-visualizer-simple/)

## Features
- Visualize audio input using Web Audio API
- Supports selecting audio input device
- Offers options for different visualization modes

## Requirements
This project requires a modern browser with support for the Web Audio API.

## Usage
1. Open the [live demo](https://code4fukui.github.io/audio-visualizer-simple/) in a compatible browser.
2. Select the desired audio input device from the dropdown.
3. Adjust the input gain using the slider.
4. Choose the visualization mode from the dropdown.
5. Your audio input will now be visualized on the canvas.
